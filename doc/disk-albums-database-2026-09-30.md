# 磁盘目录相册与 SQLite 变更

## 界面及使用方式

侧栏分成两个 section：上方“磁盘目录”，下方“系统相册”。即使未授权系统照片图库，也可以添加和浏览磁盘目录。

- 点击“添加目录…”选择根目录，后台递归扫描图片。
- 点击目录显示缩略图；点击图片进入大图，支持前后切换和返回。
- 刷新按钮对当前磁盘目录重新扫描；系统相册仍使用原有 Photos 刷新流程。
- 目录右键菜单支持重新扫描和“从列表移除（保留原图）”。
- 重启后读取 SQLite 中的目录和图片索引，按需通过安全作用域书签读取图片；不会在启动时扫描所有目录。
- 权限失效时，可重新添加同一路径以更新书签；陈旧书签在重新扫描时更新。

## 存储选择

继续使用 `PhotoMetadataCache` 管理的 `photo-metadata.sqlite` 和同一个串行数据库队列。不修改 SwiftData 的 `Item` 或它的 schema；已有 Photos ID、识别缓存和人物标注保持不变。

原图不复制进数据库，也不会因移除目录索引而删除。数据库仅增加以下两张表。

### disk_directories

| 字段 | 类型/约束 | 用途 |
| --- | --- | --- |
| directory_id | TEXT PRIMARY KEY NOT NULL | `directory:` 加 UUID，稳定目录标识 |
| display_name | TEXT NOT NULL | 目录显示名称 |
| last_known_path | TEXT NOT NULL UNIQUE | 最近已知路径及同路径去重，不代替访问授权 |
| security_scoped_bookmark | BLOB NOT NULL | 系统选择器授权后创建的只读安全作用域书签 |
| last_scan_at | REAL，可空 | 上次成功提交扫描结果的 Unix 时间 |

### disk_images

| 字段 | 类型/约束 | 用途 |
| --- | --- | --- |
| image_id | TEXT PRIMARY KEY NOT NULL | `disk:` 加 UUID，与 Photos ID 区分 |
| directory_id | TEXT NOT NULL，外键 | 所属根目录，删除目录时级联清理图片索引 |
| relative_path | TEXT NOT NULL | 相对于根目录的文件路径 |
| modification_time | REAL NOT NULL | 文件修改时间 |
| byte_size | INTEGER NOT NULL | 文件字节数 |
| pixel_width / pixel_height | INTEGER NOT NULL | ImageIO 读取的原始像素尺寸 |
| scan_generation | TEXT NOT NULL | 本次成功扫描的 UUID，用于清理未出现的记录 |

约束与索引：

- `UNIQUE(directory_id, relative_path)`：同一根目录下重复扫描不会重复入库。
- `disk_images_directory_index`：按根目录读取图片索引。
- `ON DELETE CASCADE`：仅清理数据库行，不触碰文件。

## 迁移和扫描一致性

1. 打开数据库后，在事务内执行新增表和索引的 `CREATE ... IF NOT EXISTS`；可重复执行，不重建或清空旧表。
2. 新表迁移检查 SQLite 返回码；失败回滚本次新表迁移。旧表已有的迁移逻辑不在此次重构范围内。
3. 目录枚举和 ImageIO 信息读取在后台任务执行，不占用主线程或 SQLite 队列。
4. 完整扫描成功后，将 upsert、旧索引清理及 `last_scan_at` 更新放进同一事务；失败回滚。
5. upsert 保留已有 `image_id`，更新尺寸、修改时间、大小及扫描批次。
6. 枚举失败、目录离线或任务取消时，不提交扫描快照，不清理旧索引。
7. 提交扫描结果前校验数据库 URL，防止扫描期间切换数据库后写入另一个库。

目前是增量、幂等建表，没有引入统一的 `PRAGMA user_version` 版本体系。未来修改已有列或重构全库 schema 时，应增加显式版本迁移；不能依靠 `IF NOT EXISTS` 完成列结构升级。

## 文件访问和边界

- 默认跳过隐藏文件、应用包内部和符号链接，不跟随目录链接。
- 使用 ImageIO 判断图片及提取尺寸，不只依赖扩展名；无法识别的文件跳过。
- 图片读取期间持有安全作用域访问权限；缩略图和大图使用降采样并应用图片方向。
- 只恢复用户保存的目录，不扫描未选择的位置。
- 目录书签属于本机授权信息；复制数据库到另一台机器不保证保留访问权限。
- 设置中的数据库复制会一并复制目录书签与图片索引；覆盖目标数据库也会覆盖目标的目录清单、缓存和人物标注，确认提示已更新。

## 当前范围和后续扩展

- 磁盘图片支持目录索引和浏览，尚未接入 Ollama、人脸识别、人物相册或识别文字搜索；选择磁盘目录时批量识别按钮禁用。
- 当前人物相册仍只解析 Photos 资产。后续接入磁盘识别，需要将 `PHAsset` 专用取图、缓存入口及批量任务改为统一图片来源接口，并按文件修订失效缓存。
- 文件重命名或移动到另一个相对路径按新图片处理；不根据文件内容去重。
- 同一路径重新添加会更新原记录；父子目录可以分别添加，重叠图片分别建立索引。
- 没有文件系统实时监听，新增或删除文件后需手动刷新。
- 扫描结果先在内存中收集，随后一次事务提交；超大目录的流式暂存和分页展示可另行优化。

## 验证

新增单元测试使用内存 SQLite 和临时图片目录，不以用户真实目录作为测试样本，覆盖：

- 增量迁移幂等、旧 Photos 数据保留、迁移失败回滚。
- 重扫 ID 稳定、属性更新、缺失文件清理、空目录。
- 索引写入失败回滚、目录删除的级联与隔离。
- 嵌套目录、大小写扩展名、坏文件、隐藏目录、应用包和符号链接。
- 书签解析、缩略图降采样以及越界相对路径拒绝。

真实外部目录的系统选择器授权、跨应用重启授权恢复及外置盘断连仍需实际环境验收；临时目录书签测试不等同于这些系统权限场景。
